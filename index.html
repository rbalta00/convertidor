📚 Documentación Rápida

1️⃣ Instalación

Clona el repo y ejecuta npm install

npm install

2️⃣ Configuración

Copia .env.example a .env y completa credenciales

cp .env.example .env

3️⃣ Cloudinary

Obtén credenciales en cloudinary.com/console

CLOUDINARY_CLOUD=xxxx

4️⃣ Shopify

Crea app en tu tienda y obtén token

SHOPIFY_TOKEN=shpat_

5️⃣ Ejecutar

Corre el generador de landings

npm run generate

6️⃣ Usar

En Cowork: "Genera landing de [producto]"

/skill convertidor

Ejemplo de Uso

"Genera landing de: - Nombre: Lluvia Cero 3L - Precio: $499 - Problema: Goteras en casa - Beneficio 1: Protección 10 años - Beneficio 2: Aplicas tú solo - Beneficio 3: 10x más barato"
