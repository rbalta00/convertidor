## 🚀 INSTALACIÓN RÁPIDA (10 minutos)

### PASO 1: Instalar dependencias
```bash
cd [carpeta-del-plugin]
npm install
```

### PASO 2: Obtener credenciales

#### Cloudinary (2 minutos)
1. Ve a https://cloudinary.com/console
2. Settings → API Keys
3. Copia: Cloud Name, API Key, API Secret

#### Shopify Token (3 minutos)
1. Tu tienda Admin → Settings → Apps and integrations
2. Develop apps → Create app
3. Nombre: "Landing Generator"
4. Scopes: `write_pages`, `read_pages`
5. Install app
6. Copia el token (empieza con `shpat_`)

### PASO 3: Configurar .env
```bash
# Copia el template
cp .env.example .env

# Abre y llena con tus credenciales
nano .env
```

Resultado:
```
CLOUDINARY_CLOUD=xxxxx
CLOUDINARY_KEY=xxxxx
CLOUDINARY_SECRET=xxxxx
SHOPIFY_STORE=tu-tienda.myshopify.com
SHOPIFY_TOKEN=shpat_xxxxx
DEFAULT_WHATSAPP=5251234567890
```

### PASO 4: Probar
```bash
node landing-generator-skill.js
```
